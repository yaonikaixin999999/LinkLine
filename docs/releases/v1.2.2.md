# LinkLine 1.2.2

发布日期：2026-11-05。

LinkLine 1.2.2 默认不再附带音源脚本，支持仅在本地移除 B 站收藏夹和视频，并改进试听识别、下一首预加载及搜索体验。

## 音源与配置

- 新安装默认没有导入音源，不会在首次启动或重启时自动添加脚本。
- 升级后读取音源列表时，清理旧版自动添加的预置项及其缓存，将对应的已选音源和全局首选音源恢复默认；用户手动导入的脚本继续保留。
- 恢复旧设置备份时，同样清理已移除预置项的选择，避免界面重新选中失效音源。手动导入、音源切换和全局首选设置继续可用。

需要脚本时，可在「设置与偏好 → 音源与播放」中手动导入兼容音源。平台账号、版权和会员权限仍按平台实际返回结果生效。

## B 站音乐库的本地移除

- 在侧栏右键菜单或歌单页选择「从 LinkLine 移除」，可隐藏已同步的 B 站收藏夹；支持单条或批量移除 B 站视频。
- 移除只影响 LinkLine，不删除 B 站收藏夹，也不取消视频收藏。排除记录按账号保存在本机，重新同步或登录同一账号不会自动补回。
- 登录失效时仍可移除已有同步记录；未登录 B 站时，手动添加的本地视频收藏也可正常移除。其他平台的歌单操作保持原有规则。
- 确认弹窗说明操作范围，写入失败时保留原记录并显示错误，重复点击不会重复提交。

## 播放与预加载

- 播放前读取实际音频时长，识别音源未标注的截短试听片段，继续尝试同版本完整资源；最终只有试听可用时明确显示「试听」。
- 加载失败、时长校验超时或已排除的地址继续进入回退；为导入音源请求设置有界等待，避免失效候选长期阻塞其他资源。
- 当前歌曲播放一段时间后提前准备下一首，资源过期前重新准备；切歌、播放模式、音质或首选音源变化时使旧任务失效，失败探测允许重试并释放资源。

音频可用性和实际音质仍取决于平台接口、网络、账号及歌曲权限，不会绕过会员或版权限制。

## 搜索与日常使用

- 调整歌手搜索结果的展示、平台切换及同平台多个条目的选择；改进波点歌手和专辑作品的分页读取。
- 切换页面时清理顶部残留的搜索文字，调整搜索结果标题与操作区布局。
- 启动时清理临时文件以及网页资源、代码缓存，保留账号会话、音乐库和设置。
- 更新 README 截图，展示当前版本的界面。
